## 🌸 about

`owisbot` is a multipurpose Discord bot project built using `discord.js`.

this project is focused on creating useful, clean, and community-oriented systems for the OWIS server, from moderation tools to utility features and server automation.

---

## ✨ features

* moderation systems
* slash commands
* event handling
* cooldown handling
* transcript support
* sqlite database integration
* modular command/event structure
* custom OWIS-focused utilities

---

## 🎀 built with

* Node.js
* discord.js v14
* better-sqlite3
* dotenv
* @napi-rs/canvas

---

## 🌷 project structure

```txt
handlers/
 ├─ commandHandler.js
 └─ eventHandler.js

commands/
events/
utils/
```

organized with a modular structure for easier scaling and maintenance ✿

## ⚙️ setup

### 1. clone the repository

```bash
git clone https://github.com/yourusername/owisbot-discordjs.git
cd owisbot-discordjs
```

### 2. install dependencies

```bash
npm install
```

### 3. configure environment variables

create a `.env` file using `.env.example`

```env
DISCORD_TOKEN=your_bot_token
```

### 4. start the bot

```bash
npm start
```

---

## 💗 development

run the bot with nodemon:

```bash
npm run dev
```
